# 關卡1: Tower Room
**通關目標: 一位玩家待在中央的塔上，直到倒數計時結束**
<img width="1232" height="626" alt="image" src="https://github.com/user-attachments/assets/2f49cb13-ea30-4675-bd49-a88d52daf712" />
## 關卡機制
- 場地周圍時不時會出現黃金踏板可以將你送到塔頂。
- 每隔一段時間，場地四周的水晶下方會生成Decaying Parasite，如果在時間內沒有將它們擊殺，它們會使中央的塔Decay一段時間，處於Decay狀態的塔無法站人。

<img width="369" height="396" alt="image" src="https://github.com/user-attachments/assets/e4650437-7f6f-4951-b30f-53aed537427e" />

## 關卡攻略建議
1. 隨時四處巡邏，不要放掉任何一隻Parasite。
2. 有遠程怪會去攻擊塔上的玩家，塔上的玩家建議有些坦度或回血能力。

# 關卡2A: Clouds Room
**通關目標: 在30秒內擊殺三隻Crystalline Decay，並重複三次**
<img width="1234" height="625" alt="image" src="https://github.com/user-attachments/assets/ddf0d858-0482-4ff7-af70-59cbda1d7bc2" />

## 關卡機制
- 所有玩家自帶+10跳躍高度。
- 從雲朵上掉落會有5秒重生時間。
- Crystalline Decay即將出現的雲朵上會有黑色光柱。

## 關卡攻略建議
1. 雖然不會真的死，但還是盡量不要掉下雲朵。
2. Crystalline Decay出現時旁邊會伴隨著多隻小怪，它們都有擊退玩家的能力，需注意。
3. Crystalline Decay本身的爆炸攻擊有可觀的傷害，需要注意。

# 關卡2B: Resource Room
**通關目標: 收集10個Light Crystal**
<img width="1204" height="622" alt="image" src="https://github.com/user-attachments/assets/736fe86b-4f24-4d7f-a4dd-b69b031a04c6" />
## 關卡機制
- 小王
擊殺小王Athanatic Witness以獲得2個Light Crystal。

<img width="728" height="728" alt="image" src="https://github.com/user-attachments/assets/dcf3d792-1e31-48b7-be72-9b3dd0836726" />

- 跑酷
如果你有打過Eldritch Outlook地城，你應該記得裡面很好玩的隱形跑酷。這裡是那個跑酷的倒反版，地城裡要看的是腳下，這裡要看的是頭上，跑到終點就可以拿到1個Light Crystal。
跑酷區禁用位移技，並且玩家每次掉落時，都會隨機生成出新的跑酷地圖。
玩Wynncraft的有四種人:
~~第一種是覺得這跟EO跑酷差不多的人，第二種是覺得這比EO還簡單的人，第三種是覺得這比EO還難的人，第四種是根本不會跑酷的人。~~

<img width="670" height="578" alt="image" src="https://github.com/user-attachments/assets/34601f79-e49b-44bf-97ec-004f48e83f78" />

- 解謎
和TCC第三關的防守Astal類似，一樣是按Shift射擊目標(可以壓著shift連射)，只是這次目標是來自空中的四面八方，不過沒那麼密集，在20秒內不被任何Decaying Atrium打到就可以獲得兩個Light Crystal。

## 關卡攻略建議
1. Athanatic Witness有一定強度，注意它的攻擊。
2. 遍布關卡各處的小怪Light也有一定強度，別掉以輕心。
3. 跑速慢的玩家不適合此跑酷。
4. 解謎的射擊有時候會有點謎，但是能過就好。
5. 目前最快打法是所有玩家一起去刷小王

# 關卡3A: Tower Room

# 關卡3B: Maze Room
**通關目標: 跟著持有Light Crystal玩家的指引走過隱形迷宮，完成指定任務，來到終點**

**本關卡只要超過一個人不懂機制體驗就會下降非常多，所以新手必須重點閱讀**

<img width="1230" height="623" alt="image" src="https://github.com/user-attachments/assets/b45c92b6-e914-4ed7-afe1-9a9c147bdea0" />

## 關卡機制
- 迷宮為隨機生成，只有持有Light Crystal的玩家看得到路。
- 掉下去會回到起點並受到傷害。
- ⭐ Light Crystal持有者走一段路後會來到Checkpoint(黃金平台)，這時所有玩家都需要到Checkpoint集合。

<img width="1015" height="610" alt="image" src="https://github.com/user-attachments/assets/c316c0f0-efe2-4958-940b-986a6e954d24" />

- ⭐ 在所有玩家到達Checkpoint後，之前的路徑會生出最多兩個鐵平台，**持有Crystal的玩家要待在黃金平台上，而其餘玩家需要回去站在鐵平台上**。所有鐵平台上都至少需要有一位玩家站立。**此步驟會需要重複兩次**，Checkpoint才會建立成功。

<img width="670" height="418" alt="image" src="https://github.com/user-attachments/assets/c359ff8d-d98e-42bb-9944-afc9fb77f17f" />

- 一共會需要建立三次的Checkpoint，最後一次是在終點前。

- 如果非持有Light Crystal的玩家有兩位已死亡，鐵平台只會出現一個

- 如果Light Crystal持有者死亡，整個隊伍就必須從起點開始。

- 一共會需要建立三次的Checkpoint，最後一次是在終點前，完成即破關。

## 關卡攻略建議
1. 拿Light Crystal的玩家需要有一定的生存能力。
2. 不需要跟著Light Crystal持有者走迷宮，等到對方在Checkpoint停下來後再用位移技過去集合也可以
3. 第三次Checkpoint位置一定是在場地的彩色玻璃終點前，所以第二個Checkpoint建立後，就可以跳過迷宮直接到第三次Checkpoint的位置。
4. 此關卡怪物又多又煩，低Ehp玩家需一直待在補師旁邊。
5. 此關對Archer和Shaman可能不太友善。

# Boss戰: Orphion, Fading Light(第一階段)
<img width="432" height="439" alt="image" src="https://github.com/user-attachments/assets/efbf49b7-ab72-4a0f-90ff-045d04fcb221" />

## Boss機制
### 彈幕
記得，在場地上看到基本上所有的實體，像是光柱、地上的火、Boss往你發射的碎片、太陽噴出來的小火焰、黑洞吸進去的黑色不明物體，**這些都會讓你受傷**。

### 灼燒(Guild Raid)
受到光柱、碎片、衝刺技能在地上留下的火、Orphion的嘶吼技能的傷害，均會使玩家的最大血量下降，並且效果可疊加，持續10秒後恢復，10秒之間如果再受到灼燒會使計時重置

## Boss技能
🟨 威脅沒到很高，視情況迴避。

🟧 有威脅，建議迴避，除非你相信自己。

🟥 迴避這個攻擊應該要是打這個boss的基本認知。

- 🟨/🟧 普攻
Boss會使用頭槌攻擊其仇恨所在的玩家，頭槌會召喚多道光柱，每道光柱消失後也會同時往前發射多個藍色碎片，並時不時從自身召喚出4道光柱分別往Boss的前、後、左、右方移動。

- 🟧/🟥  光球
Boss會丟出光球，對在空中的玩家有極大威脅，並持續在其底下召喚小型光柱，光球消失後，底下會爆出更多的小型光柱。

- 🟧  衝撞
Boss會吼叫一聲，接著開始四處衝撞，所經之處都會留下光柱，光柱消失後會在原地留下火焰，一段時間後消失，火焰消失時會朝左右兩旁發射藍色碎片。(Boss造成的傷害離牆越近會越高，撞到牆的那一下是最痛的)

- 🟨/🟧  擊飛
Boss會在自己前方召喚多道光柱，如果有玩家這時待在Boss面前，將會受到多次傷害和朝上方向的擊退。

-  🟧  嘶吼
Boss會先向後退，接著往前方大吼，持續擊退並傷害大範圍扇形內的所有玩家，如果Boss在半血以下，這個招式還會給予抗性和攻擊力提升。

- 🟧  雷電
血量45%以下後才會釋放，Boss會從自身先召喚出多隻小蟲，接著Boss和每隻小蟲周圍都會出現魔法陣(Boss的魔法陣涵蓋範圍最大，小蟲的較小)，同時Boss會開始蓄力，站在魔法陣裡的玩家螢幕上也會出現⚡**CHAIN**⚡警告字樣。
一段時間後，Boss降下雷電，在Boss魔法陣裡的玩家將會無法移動一段時間接著受到傷害並吸取魔力，還會獲得-75/5s Mana Regen和-8 tier attack speed效果一段時間，小蟲魔法陣裡的玩家只會受傷和吸魔力，不會有以上效果。

- 🟧 小怪
Boss戰開始後場地就會開始生成兩種小怪，白色小怪Pearl Overwatch和黑色小怪Infection Ad Infinitum。
Pearl Overwatch: 近戰，被攻擊的玩家會受到緩速和虛弱debuff。
Infection Ad Infinitum: 遠程，沒有傷害，但是被攻擊的玩家會被吸取魔力，打死會分裂。

- 🟥  Crystalline
於Boss的血量來到70%、40%時出現，一次出現4個，會在場地四處徘迴，並幫Boss補血。殺掉它會使擊殺者逐漸被水晶凍住，被凍住後將被定在原地，並無法攻擊和使用任何技能。需要隊友攻擊幫助解凍或殺掉場上所有的Crystalline才會解除，或是等它自動崩壞，但這樣會對被冰凍的玩家造成大量傷害。(有人被凍住會有系統提示)

<img width="432" height="375" alt="image" src="https://github.com/user-attachments/assets/7cfea9e7-857f-44ac-b42c-b5cf5c433053" />

- 🟧  黑洞
當Boss的血量來到50%時，Boss會進入無敵並前往中心，接著召喚出太陽並清掉所有小怪，太陽會發射出多個火焰攻擊玩家(其實就是Lightbender的大招)，隨後太陽坍縮成黑洞，掉到地上，開始將所有玩家往中間吸。在黑洞裡會持續受到傷害，黑洞同時也會吸收多個碎片，碎片打到玩家也會造成傷害。黑洞結束時，會對在黑洞範圍內的玩家造成大量傷害，同時向四周發射剛剛的黑色碎片。

<img width="739" height="374" alt="image" src="https://github.com/user-attachments/assets/462a37cd-5061-4267-8c38-11d6b8119100" />

<img width="731" height="374" alt="image" src="https://github.com/user-attachments/assets/8f65306d-205e-465e-bf9f-772b0aadb5b4" />

-  🟧 暴走
Boss(Orphion)血量歸零後，會進入無敵，之後大吼一聲清掉場上所有小怪，接著同時持續釋放光球和衝撞這兩招，最後Boss會回到中央猛力跺腳，第一階段結束。

# Boss攻略建議(Orphion)
- 光球本體內部傷害很高，飛天玩家需要閃避。
- Boss嘶吼時可以繞到Boss側邊或身後，它打不到你，這是絕佳的輸出機會。
- 雷電蓄力時，可以對Boss多打一點輸出，等到雷電即將落下時再逃離。
- Crystalline出現時全隊優先攻擊Crystalline，除非你們有把握直接把Boss的血條直接蒸發到下一波的清怪。**
- 如果你被凍住而你的隊友沒有注意到你時，你可以在聊天室打"c"，這就是代表我被凍住了，快來救我的意思。

# Boss戰: The Parasite(第二階段)
<img width="651" height="651" alt="image" src="https://github.com/user-attachments/assets/7b5fe511-481c-436b-be7f-6eada6619de4" />

## Boss機制
### 寄生
- Boss會對即將寄生的玩家放出一道光線，接著跳到該玩家身上並寄生對方，看到光線立刻釋放位移技可以躲開。
- 被Boss寄生時，你的技能會被Boss奪走，你無法釋放任何技能，Boss會根據你的職業釋放技能攻擊其他玩家。
- 螢幕上每隔一段時間會有滑鼠按鍵提示，在時間內按下正確的按鍵組合可以抵抗，成功多次便可自行解除寄生。
- 按鍵組合正常狀況下是三個鍵，場上剩下一位玩家時需要按五個，不過僅需成功一次即可解除寄生。
- 也可以透過其他玩家解除寄生，只要對Boss造成一定傷害量(最大血量10%)，Boss就會解除寄生。



# Boss技能
🟨 威脅沒到很高，視情況迴避。

🟧 有威脅，建議迴避，除非你相信自己。

🟥 迴避這個攻擊應該要是打這個boss的基本認知。

- 🟨  普攻
Boss會用手打擊前方玩家，打擊同時也會發射紫球攻擊遠方玩家。被紫球攻擊的玩家會受傷並受到感染，名條會變成紫色，在一秒後受到二度傷害並往四周發射更多紫球。

- 🟨 毒彈
Boss會投擲出一顆毒彈，毒彈會四處彈跳，一段時間後消失，被砸中的玩家會受傷並獲得緩速等負面效果，消失前的最後那一砸會造成更多傷害。

- 🟧 寄生
> 🟨 被寄生的玩家職業是Warrior:
- Bash: 向前方釋放四個Bash攻擊玩家。
- Charge: 飛走，同時攻擊經過的玩家。
- Uppercut: 彈起附近所有玩家並造成傷害，並在騰空時造成二次傷害。
- War Scream: 對前方所有玩家造成傷害並發射子彈。

> 🟨 被寄生的玩家職業是Mage:
- Metor: 召喚隕石攻擊其他玩家。
- Teleport: 傳走並傷害經過的玩家。
- Heal: 被寄生的玩家會幫Boss補血(少量)。
- Ice Snake: 被寄生的玩家會放出冰蛇攻擊並緩速其他玩家。

> 🟨 被寄生的玩家職業是Archer:
- Arrow Bomb: 發射爆炸箭攻擊，爆炸後分裂成12個小爆炸箭
- Escape: 跳走同時向後發射一堆箭矢
- Arrow Storm: 發射一堆箭矢攻擊其他玩家。
- Arrow Shield: 抵抗6下攻擊。

> 🟨 被寄生的玩家職業是Assassin:
- Spin Attack: 攻擊圓形範圍內所有玩家。
- Dash: 往前衝一小段距離，同時攻擊經過的玩家。
- Multihit: 對前方玩家造成多段傷害。
- Smoke Bomb: 發射煙霧彈，傷害所有處在煙霧內的玩家。

> 🟧 被寄生的玩家職業是Shaman:
- Totem: 放出Totem，待在Totem附近的玩家會持續受傷(被寄生玩家丟出的Totem顏色不同)。
- Haul: 往Totem方向飛。
- Uproot: 發射一個子彈，被擊中的玩家會受傷並受到大量擊退。
- Aura: Totem會放出Aura，對附近的所有玩家造成傷害。

Parasite血量歸零後，會播放一段動畫，Parasite會被Orphion吼，之後需要玩家上前給Parasite最後一擊，戰鬥才結束。

# Boss攻略建議(Parasite)
- 補師需要持續對被寄生的玩家補血以確保對方存活。
